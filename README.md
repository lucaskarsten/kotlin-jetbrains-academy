# Kotlin: JetBrains Academy

Os projetos que fiz na trilha Kotlin do JetBrains Academy (Hyperskill), em 2024.
Cada pasta era um repositório próprio; foram juntados aqui com o histórico de cada um.

| Projeto | O que é |
|---|---|
| [CoffeeMachine](CoffeeMachine/) | Máquina de café no terminal: estoque, compra, troco |
| [Zookeeper](Zookeeper/) | Primeiro projeto da trilha: saída formatada |
| [SimpleChatBot](SimpleChatBot/) | Chatbot de perguntas e respostas no terminal |
| [Simple_TicTacToe](Simple_TicTacToe/) | Jogo da velha no terminal |
| [CinemaRoomManager](CinemaRoomManager/) | Reserva de assentos de cinema e estatísticas da sala |
| [UnitConverter](UnitConverter/) | Conversor de unidades com parser de entrada |
| [ChuckNorrisCipherEncoder](ChuckNorrisCipherEncoder/) | Codificação binária em "unário" do Chuck Norris |
| [Minesweeper](Minesweeper/) | Campo minado no terminal |
